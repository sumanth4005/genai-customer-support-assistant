# Findings and Recommendations

## Summary
This project evaluates Generative AI responses for common customer-support scenarios.

## Initial Findings
The AI assistant performed well on simple and common customer questions such as password resets and general product information.

More caution was needed for sensitive scenarios such as suspicious transactions, refunds, and account-access issues.

## Key Observations
- Responses were generally clear and easy to understand.
- Simple prompts produced more consistent answers.
- Sensitive questions required stronger escalation guidance.
- Some responses could sound too confident when information was limited.
- Human review is important for higher-risk customer situations.

## Product Recommendations
- Add clear human escalation rules.
- Use approved response templates for sensitive topics.
- Improve prompt instructions for uncertain situations.
- Add guardrails to reduce unsupported claims.
- Track response quality using consistent evaluation metrics.

## Future Improvements
- Compare multiple AI models.
- Expand the evaluation dataset.
- Add more customer scenarios.
- Create a Power BI dashboard.
- Measure hallucination patterns.
