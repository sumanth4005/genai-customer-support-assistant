# Prompt Library

## Purpose
This file contains sample customer-support prompts used to evaluate how well a Generative AI assistant responds to common customer questions.

## Prompt 1: Password Reset
Customer Question:
"I forgot my password. How can I reset it?"

Evaluation Focus:
- Clear instructions
- Correct steps
- Helpful tone
- No unnecessary information

## Prompt 2: Account Access Issue
Customer Question:
"I am unable to log in to my account even though my password is correct."

Evaluation Focus:
- Troubleshooting quality
- Clarity
- Escalation guidance
- Safety

## Prompt 3: Payment Status
Customer Question:
"I made a payment yesterday, but it is still not showing in my account."

Evaluation Focus:
- Accuracy
- Clear explanation
- Appropriate next steps
- Avoiding unsupported claims

## Prompt 4: Refund Request
Customer Question:
"I want a refund for a service I did not use. What should I do?"

Evaluation Focus:
- Policy awareness
- Clear next steps
- Professional tone
- Human escalation if needed

## Prompt 5: Suspicious Transaction
Customer Question:
"I see a transaction that I do not recognize. What should I do?"

Evaluation Focus:
- Safety
- Urgency
- Correct escalation
- Avoiding risky advice

## Prompt 6: General Product Information
Customer Question:
"Can you explain the main features of this service in simple words?"

Evaluation Focus:
- Clarity
- Relevance
- Simplicity
- Completeness

## Prompt 7: Human Agent Escalation
Customer Question:
"I already tried the steps you gave me and the issue is still not fixed. Can I speak with someone?"

Evaluation Focus:
- Recognition of failure
- Escalation path
- Empathy
- Concise response
